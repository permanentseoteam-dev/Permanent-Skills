# Permanent Skill Strategy

Private community platform for compounding skills, SEO, and offers.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Admin

- Email: `admin@permanentseo.com`
- Password: `admin@permanentseo.com`

New members register, submit an application, and wait for admin approval before they can access the community.
